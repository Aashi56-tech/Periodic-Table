# 🧪 Interactive Periodic Table

This is an interactive Periodic Table project created using HTML, CSS, and JavaScript.

## ✨ Features

- Displays elements from the Periodic Table
- Shows atomic number, symbol, and element name
- Click on an element to see more information
- Different colors represent different element categories
- Simple and beginner-friendly interface

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
